# Changelog

Notable changes to Velmora are documented here. Version numbers used by the application are defined in [`VERSION`](VERSION).

## Unreleased

Changes intended for the next release will be listed here.

## 0.1.0-alpha.2.4 — 2026-10-15

### Added

- Self-hosted storefront and administrative interface.
- Browser-based installer for database, store and administrator setup.
- Storefront Builder for branding, navigation, content sections, FAQ, dialogs and footer.
- Product categories, catalog filters and optional inventory tracking.
- Order management and CSV exports for administrative data.
- Project information dialog and installed version display.
- Backup verification, restore helpers and deployment checks.

### Improved

- Responsive product presentation and administrative layouts.
- Expandable sections in the product editor and Storefront Builder.
- Category editor and nested form layouts across screen sizes.
- Checkout navigation and product loading during client-side routing.
- Storefront copy and project information presentation.

### Notes

- Velmora is alpha software. Deployments should be evaluated and backed up appropriately.
- Product variants and payment-gateway integrations are not included in the current feature set.
